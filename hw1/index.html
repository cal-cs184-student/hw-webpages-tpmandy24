These pixels can present itself as singlar pixels, lines, dots, and for this specific instance triangles. In other words, a graphic is converted and utilized as a series of pixels to create a raster image. Our algorithm is no worse than the one that checks each sample within the boundaries of the defined triangles that are displayed wihtin the smallest rectangle. We minimize the binding box of the triangle then enforce edge cases and checks to make sure it stays within bounds. This then efficiently correlates to each prospective pixel.

Task 2: Antialiasing by Supersampling

To antialias triangle edges, we implemented supersampling by evaluating multiple subpixel samples per output pixel and averaging the results. We used the provided sample_buffer, which stores sample_rate color samples for each pixel, effectively acting as a higher-resolution temporary framebuffer. The size of the sample buffer is width × height × sample_rate, and it is dynamically resized when the framebuffer size or sample rate changes. During rasterization, instead of testing a single point at the center of each pixel, each pixel is subdivided into a uniform √sample_rate × √sample_rate grid. For each subpixel sample, we evaluate whether the sample point lies inside the triangle using edge functions. If the sample is inside the triangle, the corresponding entry in the sample buffer is filled with the triangle’s color; otherwise, it remains the background color. Once all primitives are rasterized, the resolve_to_framebuffer step averages the sample_rate subpixel colors associated with each pixel and writes the resulting color to the final framebuffer. This resolves the high-resolution supersampled image back to screen resolution.

Task 3: Transforms

For Task 3, we modified svg/transforms/robot.svg to create a more dynamic pose and saved the result as my_robot.svg in the docs/ directory. Our goal was to make the cubeman appear as if the figure were waving, with one arm rotated upward at the shoulder and bent slightly at the elbow. To achieve this, we applied hierarchical transformations using SVG groups. The arm components were grouped together and rotated about their joint positions using the rotate transform, while translations were used to position the arm correctly relative to the torso. This ensured that transformations applied to parent groups correctly affected their child components. We also adjusted the proportions slightly and changed some colors to better emphasize the motion of the waving arm. The final rendered image demonstrates that the translation, scaling, and rotation transforms implemented in transforms.cpp work correctly and compose as expected under hierarchical transformation.
